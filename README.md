# 🌙 MUSE

MUSE is a calm workspace for developers, creators, and dreamers to capture ideas, organize projects, and continue building whenever inspiration strikes.

Instead of overwhelming productivity tools, MUSE focuses on one thing:
turning ideas into real projects.

---

## ✨ Features

- 🔐 User Authentication
  - Secure Signup & Login
  - Passwords encrypted using bcrypt

- 👤 Personal Dashboard
  - Dynamic greeting
  - Profile information
  - Project statistics
  - Project search

- 📁 Project Management
  - Create projects
  - Edit projects
  - Delete projects
  - Continue building existing projects

- 🤖 Muse AI Assistant
  - AI powered by Groq + Llama 3.3
  - Understands the current project
  - Gives suggestions based on:
    - Project title
    - Vision
    - Thoughts
    - Status
    - Project type

- 🎨 Responsive UI
  - Mobile friendly
  - Glassmorphism design
  - Space-inspired theme

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/Amrutavannam/muse.git
```

### Install dependencies

```bash
npm install
```

### Create a `.env` file

```env
GROQ_API_KEY=your_api_key_here
```

### Start the server

```bash
node server.js
```

Open:

```
http://localhost:3000
```

## 💡 Why MUSE?

MUSE was built around a simple idea:

Great ideas don't always arrive when we're ready.
Sometimes they appear at midnight, during a lecture, or while listening to music.

MUSE gives those ideas a place to live, grow, and become real projects—one step at a time.
